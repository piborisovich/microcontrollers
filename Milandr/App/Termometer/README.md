# Termometer

## Описание
Чтение показаний с нескольких датчиков [RS-GZ-N01](http://save.jnrsmcu.com/%E8%8B%B1%E6%96%87%E8%B5%84%E6%96%99/Light%20intensity%20transmitter%EF%BC%88Type485%E3%80%810-65535lux%EF%BC%89.pdf) (4 шт.) и их вывод  циклически на знакосинтезирующий дисплей 16x2 из комплекта arduino (LCD1602)
